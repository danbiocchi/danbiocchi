## Manifesto

I don't trust code I can't read, machines I can't see, or dependencies nobody chose on purpose.

I build small and own the stack wherever I can. I've built uncrewed vehicles in Rust, a fast web app in Rust, and AI agents that run on hardware in my own house. I'd rather understand every layer than trust the one on top.

### Engineering doctrine

Non-negotiable. Open a pull request if you want to argue.

1. **Small attack surface.** Reuse what's already installed. New software comes from a well-maintained official source, gets pinned to a version, and has to earn its place.
2. **Working beats claimed.** I run it before I say it works. If I haven't tested it, I say so.
3. **Delete what you replace.** Git keeps the history, so the working tree doesn't need old versions and scratch files lying around.
4. **Readability over sparkle.** Motion stays only while the text stays readable. Glow that hides the words gets cut first.
5. **Own the stack when it's practical.** I run models, image generation and inference on my own hardware whenever I can. Cloud is for when the job needs it, with the cost and failure modes in view.
6. **Delegate the typing, keep the judgment.** I brief coding agents clearly, check what they hand back, and own the result.

### What's on the bench

- **[hermes-vcc-engine](https://github.com/danbiocchi/hermes-vcc-engine)**: instant context compaction for Hermes Agent. It builds the summary in milliseconds with no LLM call, keeping the exact commands, exit codes, errors and files, each linked back to its original message. Based on the VCC paper.
- **[airborne-oxide](https://github.com/danbiocchi/airborne-oxide)**: uncrewed vehicles, powered by Rust.
- **[Attendex](https://github.com/danbiocchi/Attendex)**: a TypeScript app for keeping track of students.
- **A game in development**, with a Discord community I built and run. The code stays private for now.

Quieter work, all private for now: a local speech-to-text engine, an all-in-one file converter that runs in the browser, a personal workflow tool, and an experimental VPN in Rust with two layers of encryption.
